- 按模块、根因或验证面组织小批次，冻结一批后运行受影响检查，在阶段边界运行必需整体验证。每个有效循环报告完成项及证据、剩余门槛和一个首要下一步。

- 等待审查或外部资料时，可推进不冲突的兼容调用核查、故障测试准备、现有失败分析、验证证据整理。不得为等待制造无关工作。只有独立且收益明确的任务才并行；明确文件所有权和集成责任，工作者不得覆盖彼此改动，集成者重跑受影响检查。
- 里程碑先完成适用验证和独立审查，再作非空本地提交；必要的中间检查点必须明示未过门槛。默认不推送，不创建 PR。本任务无远端操作目标、部署环境或生产数据操作依据；不得由概括授权推导这些操作属于范围。
