## 执行、重试与恢复

- 按模块/根因/验证面冻结批次；api 和 web 在输入及写入范围独立时可并行，否则顺序推进。集成负责人是主 agent；共享接口、schema、lockfile、生成文件等仅一个写入者负责。worker 延期项及真正依赖它的工作排在独立工作之后。
- 如使用实现 subagent，明确专属文件与输入输出，提醒各 agent 不得覆盖或回退他人修改；主 agent 负责整合与跨模块验收。并行实现不能替代独立审查。
- 每项最多尝试三次；记录每次错误、证据、条件与恢复方案。第三次后记 waiting/deferred/needs input 并重排，禁止在相同条件下循环刷重试。已有 worker 三次失败不能因生成新 goal 而清零。
- 条件改变或阶段边界检查恢复可能；边界检查不等于无条件再发起同一失败请求。恢复前记录新证据与尝试预算依据。任何替代实现或 mock 必须如实标识，不能冒充真实外部依赖验收。
- 每个有效循环更新已完成、剩余 gate、证据和一个主要下一步。阶段结束、上下文压缩、额度等待或交接前，记录最新提交、未提交变更、验证/审查结果、等待及恢复条件。恢复时核对实际 checkout 和证据；不只依赖聊天历史。

## 项级三次尝试与原生整体 blocked：两个独立机制

- 项级计数仅控制某一任务的重试与排程；同一 goal turn 内三次尝试、三条日志、三个子任务失败或三个 reviewer 回合，均不等于三个 goal turns。
- 当前整体阻塞连续 goal-turn 计数为 0：本次只是生成目标，没有执行 goal turn；不得从 worker 的三次失败倒推整体计数。
- 每个实际 goal turn 结束时记录：宿主可验证的 turn 标识、同一整体阻塞条件的标识及证据、全部有意义剩余工作的依赖关系、已尝试的恢复/安全替代/重排、是否仍有可推进工作、连续计数。没有可靠 turn 证据时不推定计数。
- api 或 web 尚能独立推进时，整体不满足 blocked；继续执行，worker 可保持 deferred/needs input，相关 gate 开放。其他 worker 工作、验证、文档或审查仍可推进时也同理。
- 仅在恢复、安全替代与重排均已穷尽，所有有意义的剩余工作都无法推进并共同依赖同一个已证实的必需外部条件、安全边界或逻辑冲突，且这一相同整体阻塞条件连续三个实际 goal turns 被验证，并满足宿主更严格的原生审计规则时，才允许整体 blocked。该条件消失、变更或恢复有效推进时重置计数；不可人为制造空 turn 凑数。
- 原生 `update_goal` 若可用，先核实其真实 schema 和状态约束，再按宿主合同调用；needs input/deferred 是这里的项级记录，不假定为其接受的状态值。当前未暴露该工具，不伪造调用、状态回执或自动唤醒；保留本文件作为恢复入口，不以工具缺失跳过审计或将文字记录冒充原生状态。
- 配额/资源等待遵循宿主暂停规则，先 checkpoint；无已验证的非阻塞恢复能力时不承诺自动续跑、不编造 reset 时间、不忙轮询、不复制 goal。

## 行为、验证、审查与提交 gate

1. 三模块均按恢复出的批准迁移目标运行；核查相关调用方、公共接口、任务处理和数据语义、跨模块连接及兼容边界。存在持久化迁移时验证恢复、幂等/重放和回滚适用边界；具体语义以批准规格与实际代码为准。
2. 每模块执行真实的针对性验证；阶段边界执行适用的更广集成/构建/类型/CI 检查，保留原始断言、阈值和退出码。worker 真依赖恢复前，其外部集成 gate 不得宣称通过。
3. web 使用真实 Chrome browser_use 或实际可用等效浏览器，对恢复出的真实路由执行主要操作、成功与失败交互，记录 URL、动作、观察结果和截图等证据，分别记录功能、UI/UX、无障碍与适用视口结果。构建或 DOM 检查不能替代浏览器验收；缺少浏览器时继续其他工作并保留未过 gate。
4. 每个重大行为变更里程碑以及最终集成，都由 3 名独立只读 reviewer 检查当时整合后的 diff 和证据；实现者不计入。发现记录严重程度、精确位置、观察证据与建议。修复后复审受影响改动，默认最多 3 个修复/复审回合；未解决问题延期但不豁免 gate。不可用 reviewer 记为能力缺口，先推进无需审查的工作，不以自查冒充独立审查。
5. 更新受影响的迁移/运行/恢复文档及已知限制；验证与适用审查通过后本地提交持久里程碑，不做空提交。必要中间 checkpoint 可记录未过 gate，但不得宣称验收通过；默认不 push，任务实际需要且目标已核实时可使用既有范围授权。
6. 完成必须同时满足三模块真实行为、适用验证、兼容/数据约束、文档、里程碑与最终独立审查/复审。api 与 web 完成仅算部分交付，worker deferred/needs input 不算整个目标完成。

## 授权与安全

确认范围内所需、用户可授权的操作均预授权，包括 Chrome 上传、输入已有凭据、文件/依赖/环境/worktree/Git 变更、push/PR、测试及审查响应；不得仅以需要通常授权为由重新询问、等待、延期或标 blocked。执行前从证据解析真实目标并记录远程/破坏性影响。该授权不产生凭据、会话、工具或能力，不覆盖更高优先级边界，也不扩展任务范围。严禁暴露、截图、转录、保存、提交或发布凭据值；只记录脱敏动作和结果。真实能力缺口使用安全替代，继续独立工作并保留未满足 gate。
